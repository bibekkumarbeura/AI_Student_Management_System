# AI-Based Student Management System

## Project Overview
A student management application with a machine-learning-based
performance estimator for educational demonstration.

## Features
- Add student records
- View and search students
- Delete student records
- Attendance dashboard
- Marks chart
- Download student data as CSV
- Estimate performance using machine learning

## Technologies
- Python
- Streamlit
- Pandas
- NumPy
- Scikit-learn

## Installation
Install required libraries:

    python -m pip install -r requirements.txt

## Train the Model

    python train_model.py

## Run the Application

    python -m streamlit run app.py

## Note
The model uses synthetic training data. Predictions are not validated
for real-world academic decisions.
